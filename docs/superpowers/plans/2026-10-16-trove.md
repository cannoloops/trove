# Trove Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (native, chosen: user asked for no further questions). Steps use checkbox (`- [ ]`) syntax.

**Goal:** Clipboard manager macOS stile Paste con history, preview, ricerca ibrida (fuzzy+OCR+semantica), incolla plain, backup su cartella Google Drive.

**Architecture:** SwiftPM con libreria `TroveCore` (storage SQLite/FTS5, classificazione, ricerca, backup — testata con swift-testing) ed eseguibile `Trove` (AppKit+SwiftUI: NSPanel in basso, status item, settings, hotkey Carbon). `scripts/build.sh` assembla e firma `Trove.app`.

**Tech Stack:** Swift 6.2, SwiftUI/AppKit, SQLite3 C API, Vision, NaturalLanguage, LinkPresentation, ServiceManagement, Carbon HotKey.

**Spec:** `docs/superpowers/specs/2026-10-16-trove-design.md`

## Global Constraints
- macOS deployment target 15.0; nessuna dipendenza esterna.
- Dati in `~/Library/Application Support/Trove/` (`trove.sqlite`, `blobs/`).
- Mai salvare elementi con tipi `org.nspasteboard.ConcealedType` o `org.nspasteboard.TransientType`.
- Retention: nessuna cancellazione automatica.
- Hotkey default ⇧⌘V. Bundle id `io.trove.app`. Firma con identità "Trove Local Signing".
- Backup in `<GoogleDrive>/My Drive/Trove/` ogni 24 h + manuale.

## Review Focus
- Immagine enorme (screenshot 5K) copiata: no blocco UI → OCR/embedding/thumbnail in background; test `ingestDoesNotBlock` non pratico, coperto da `Task.detached` + test su `Store.insert` con blob.
- Stesso testo copiato due volte: un solo elemento, portato in cima (test `dedupMovesToTop`).
- Query con caratteri FTS speciali (`"`, `*`, `-`, `(`): nessun crash, risultati sensati (test `searchEscapesSpecialChars`).
- Query di 1–2 caratteri (trigram richiede ≥3): fallback LIKE (test `shortQueryUsesLike`).
- Cartella Google Drive assente: backup segnala errore chiaro, non crasha (test `backupWithoutDriveThrows`).

### Task 2: Modello + Store
**Files:** `Sources/TroveCore/ClipItem.swift`, `Store.swift`; Test `Tests/TroveCoreTests/StoreTests.swift`
**Produces:**
- `enum ClipKind: String { text, richText, link, image, file, color }`
- `struct ClipItem { id: Int64; kind; text: String; rtf: Data?; html: String?; blobPath: String?; filePaths: [String]; sourceApp: String?; sourceBundle: String?; createdAt: Date; hash: String; ocr: String?; title: String?; embedding: [Float]?; embeddingLang: String? }`
- `final class Store { init(directory: URL) throws; func insert(_: ClipItem) throws -> Int64 /* dedup by hash, bumps createdAt */; func recent(limit:offset:) -> [ClipItem]; func get(_ id) -> ClipItem?; func delete(_ id); func update(ocr:title:embedding:lang:for:); func ftsSearch(_ q: String, limit: Int) -> [Int64]; func all() -> [ClipItem] }`
- [ ] Test `dedupMovesToTop`, `shortQueryUsesLike`, `searchEscapesSpecialChars`, `ftsMatchesOCRText`. Fallire → implementare → passare → commit.

### Task 3: Classificazione pasteboard
**Files:** `Sources/TroveCore/Classifier.swift`; Test `ClassifierTests.swift`
**Produces:** `Classifier.kind(forText:) -> ClipKind` (link se URL http(s) singolo, color se `#RGB/#RRGGBB/rgb()`), `Classifier.hash(_ data: Data) -> String` (SHA256 via CryptoKit).
- [ ] Test: `https://apple.com` → link; `#ff8800` → color; `ciao` → text. Commit.

### Task 4: Ricerca ibrida
**Files:** `Sources/TroveCore/Search.swift`, `Embedder.swift`; Test `SearchTests.swift`
**Produces:**
- `struct Query { text; kinds: Set<ClipKind>; app: String?; since: Date? }`, `Query.parse(_ raw: String) -> Query` — token `type:image|link|text|file|color`, `app:<nome>`, `today`/`oggi`, `week`/`settimana`.
- `Embedder.embed(_ text) -> (vec:[Float], lang:String)?` (NLEmbedding sentence it/en via NLLanguageRecognizer, default en).
- `Search.run(_ q: Query, store: Store, limit: Int = 200) -> [ClipItem]`: empty text → recent filtrati; else score = FTS hit 1.0 + fuzzy subsequence (0…0.6) + semantic (1 − dist/2, solo se ≥ soglia 0.55 e stessa lingua) → ordinati.
- [ ] Test `parseFilters`, `fuzzyTypoFinds` ("aple" trova "apple"), `filtersByKind`, `semanticFindsSynonym` (it: "appuntamento dentista" trova "visita odontoiatrica" tra 3 testi). Commit.

### Task 5: Backup Drive
